# OceanFic

**海洋资产风控及智能管理平台**

[English](README.md)

## 概述

OceanFic 是一个基于 **Rust** 和 **Bevy 引擎**构建的高性能3D海洋资产风控及智能管理平台。在交互式3D地球上提供海洋资产的实时可视化与管理、环境监测和风险评估能力。

## 功能特性

### 🌍 地球与海洋可视化
- 3D交互式地球，含海洋/陆地渲染
- 轨道相机，支持缩放、平移和旋转
- 实时网格叠加和坐标系统
- 图层化渲染：按资产类型、风险等级与时间轴筛选
- 专题视图：风险热力图与资产状态着色

### 🌦️ 海洋环境与气象
- 台风/飓风/风暴追踪与模拟
- 洋流系统（墨西哥湾流、黑潮、南极绕极流等）
- 海况要素：有效波高、涌浪、风暴潮
- 上升流与下降流区域监测
- 地质灾害监测：地震、海啸、海底滑坡
- 气候变化趋势：海平面、海洋热浪
- 气象与海况对海洋资产的影响分析及作业窗口判定

### 📡 资产管理
- **跨洋光缆** — 光缆路由、容量、状态监控
- **海底电力电缆** — 出口电缆、阵列间电缆、互联电缆
- **海上风电光伏** — 风机集群、海上光伏、海上升压站、输电线路
- **油气平台** — 固定式/半潜式/FPSO平台、管网系统
- **船舶管理** — 油轮、LNG运输船、货船、渔船/养殖船、实时定位
- **航道管理** — 航运通道、专属经济区边界、渔业区、限制区域
- **岸基设施** — 运维母港、接收站、变电站，支撑出海运维与并网判定

### 🐋 海洋生态
- 生态群落区域映射（珊瑚礁、海藻林、红树林、深海热泉）
- 物种群追踪（鲸类、海龟、鱼群、海洋哺乳动物）
- 迁徙路线可视化与季节性模式分析
- 保护区与生态红线叠加

### ⚠️ 风控系统
- 多因子风险评估引擎（气象、洋流、结构、运营、环境、地缘政治、地质灾害、气候变化）
- 实时预警系统，严重等级（信息 → 紧急）
- 风险评分与分级（极低 → 危急）
- 风险聚合（单因子 → 资产 → 区域）
- 告警处置（确认/升级 → 处置任务 → 结果回写）

## 快速开始

### 构建与运行
```bash
# 克隆仓库
git clone https://github.com/fn-a/oceanfic.git
cd oceanfic

# 开发模式运行
cargo run

# 发布构建
cargo build --release
```

### 操作

| 操作 | 按键 |
| --- | --- |
| 旋转 / 平移 / 缩放 | 左键拖动 / 右键拖动 / 滚轮 |
| 抬高 / 降低相机 | `Page Up` / `Page Down` |
| 昼夜光照 ↔ 均匀光照（无昼夜） | `L` |

### 底图数据

`assets/` 下使用两档预生成的 [GSHHG](https://www.soest.hawaii.edu/pwessel/gshhg/) 2.3.7
数据，启动时读取一次（先找与可执行文件同级的 `assets/`，再回落到工作目录下的 `assets/`）：

| 文件 | 来源 | 环数 / 点数 | 体积 | `altmax` |
| --- | --- | --- | --- | --- |
| `coasthi.bin` | GSHHG 2.3.7 shapefiles，**full** 分辨率 | 188,275 / 10,587,877 | 81.5 MB | **0.16**（约 1,020 km）|
| `coastlo.bin` | 同上，**intermediate** 分辨率 | 40,970 / 450,926 | 3.6 MB | ∞（始终可用）|

格式：24 字节头（magic `OFBM`、版本、`altmax`、点数、xxh32 校验、flags）+ i32 微度 delta 载荷，每条环的增量序列各自从 0 开始。

任意一档 `.bin` 缺失或损坏时，程序仍会正常启动（只是暂时不显示海岸线数据），并由后台线程补齐：

1. 同时探测 [SOEST 镜像](https://www.soest.hawaii.edu/pwessel/gshhg/gshhg-shp-2.3.7.zip) 与
   [GitHub Release](https://github.com/GenericMappingTools/gshhg-gmt/releases/tag/2.3.7)，
   走可访问且更快的路线下载 `gshhg-shp-2.3.7.zip`（约 142 MiB）；
2. 将压缩包缓存到可执行文件同级的 `cache/`，不存在时使用工作目录下的 `cache/`；
3. 从包中取出所需的 `L1`–`L5` shapefile，按与上表相同的格式烘焙到 `assets/`；
4. 热加载到正在运行的程序中。

进度会以 `[basemap]` 前缀输出到控制台。下载失败（例如离线）时程序继续无底图运行，下次启动再试。

# OceanFic

**海洋资产风控及智能管理平台**

[English](README.md)

## 概述

OceanFic 是一个基于 **Rust** 和 **Bevy 引擎**构建的高性能3D海洋资产风控及智能管理平台。在交互式3D地球上提供海洋资产的实时可视化与管理、环境监测和风险评估能力。

## 功能特性

### 🌍 地球与海洋可视化
- 3D交互式地球，含海洋/陆地渲染
- 轨道相机，支持缩放、平移和旋转
- 实时网格叠加和坐标系统

### 🌦️ 气象与洋流
- 台风/飓风/风暴追踪与模拟
- 洋流系统（墨西哥湾流、黑潮、南极绕极流等）
- 气象对海洋资产的影响分析
- 上升流与下降流区域监测

### 📡 资产管理
- **跨洋光缆** — 光缆路由、容量、状态监控
- **海上风电** — 风机集群、海上升压站、输电线路
- **油气平台** — 固定式/半潜式/FPSO平台、管网系统
- **船舶管理** — 油轮、LNG运输船、货船、渔船/养殖船、实时定位
- **航道管理** — 航运通道、专属经济区边界、渔业区、限制区域

### 🐋 海洋生态
- 生态群落区域映射（珊瑚礁、海藻林、红树林、深海热泉）
- 物种群追踪（鲸类、海龟、鱼群、海洋哺乳动物）
- 迁徙路线可视化与季节性模式分析

### ⚠️ 风控系统
- 多因子风险评估引擎（气象、洋流、结构、运营、环境、地缘政治）
- 实时预警系统，严重等级（信息 → 紧急）
- 风险评分与分级（极低 → 危急）

## 快速开始

### 构建与运行
```bash
# 克隆仓库
git clone https://github.com/fn-a/oceanfic.git
cd oceanfic

# 开发模式运行
cargo run

# 发布构建
cargo build --release
```
